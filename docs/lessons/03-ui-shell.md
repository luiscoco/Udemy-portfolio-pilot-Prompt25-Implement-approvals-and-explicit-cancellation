# 03 — The accessible UI shell

The browser application lives only in `apps/web`. React Router declarative routes render Dashboard (`/`), Portfolios (`/portfolios`), News (`/news`), Assistant (`/assistant`), Watchlist (`/watchlist`), and Settings (`/settings`). A shared sidebar becomes a dismissible drawer at tablet widths. The top bar holds a portfolio selector; selecting a different demo portfolio updates the summary and holdings views. A skip link, named navigation, table caption and column headers, form labels, visible focus styles, and keyboard-operable controls give the shell a usable foundation.

`app.tsx` composes reusable `Heading`, `PageTitle`, `HoldingsTable`, `NewsList`, `ChatPanel`, and `DataState` components. `DataState` covers empty, loading, error, and stale conditions. Chat is intentionally disabled and labeled as a preview until milestone 04 provides the first agent endpoint. The news, prices, and portfolio figures are deterministic examples and are explicitly marked as demo data in the UI. CSS in `styles.css` is the single styling approach, with responsive breakpoints and no UI component runtime dependency.

Browser-safe DTO schemas live in `packages/contracts`; fixture instances live in `apps/web/src/data/demo.ts`. Money and quantities travel as decimal strings. `apps/web/src/lib/format.ts` performs display formatting only. It does no valuation or gain calculation; those belong in the domain and API in later milestones. Fixture timestamps use UTC and the UI displays that zone.

`apps/web/src/lib/api-client.ts` is the browser API boundary. It accepts a Zod response schema and an `/api/` path, parses the shared error envelope, and returns typed failures for HTTP, malformed JSON/schema, network, timeout, and caller cancellation. It combines the caller's abort signal with a request timeout and removes the listener when done. TanStack Query owns server state, starting with the health check, and passes its cancellation signal through the client. Portfolio, news, and watchlist data are local fixtures at this milestone, not pretend API responses.

Run `npm run dev` and open `http://127.0.0.1:5173/`. Change the portfolio in the header, visit each route, narrow the browser below 650 pixels, open and close the menu, and use Tab and Enter to traverse navigation. Run `npm run test:browser --workspace=@portfolio-pilot/web` for Chrome desktop/mobile, selector, and keyboard smoke checks. The demo remains usable if the API is unavailable; it shows an error state with retry.
